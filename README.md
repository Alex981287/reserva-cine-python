# Reserva de Asientos de Cine

## Nombre del estudiante
ALEX EDUARDO TANGUILA GREFA

## Objetivo

Crear un programa en Python que permita gestionar la reserva de asientos de una sala de cine mediante una matriz de 3 filas por 4 columnas.

## Cómo ejecutar el programa

1. Tener Python instalado en el computador.
2. Abrir una terminal en la carpeta donde se encuentra el archivo.
3. Ejecutar el siguiente comando:

python reserva.cine.py

4. Ingresar la fila y la columna del asiento que se desea reservar.
5. El programa mostrará el estado completo de la sala.
